# 모듈 2. 실습용 솔루션 만들기와 초기 설정

## 학습 목표

- 환경과 솔루션의 차이를 이해합니다.
- 회사 정책에 따라 사용 가능한 Power Platform 환경에 본인 실습용 비관리형 솔루션을 만듭니다.

## 사전 준비

- 회사 정책에 따라 교육용으로 사용 가능한 Dataverse 데이터베이스가 존재하는 Power Platform 환경
- 해당 환경에서 솔루션을 생성하고 게시자를 선택하거나 생성할 수 있는 권한
- 본인의 회사·교육 계정과 강사가 지정한 개인 식별자(예: `u001`)

```{important}
사내 운영 정책에 따라 교육용으로 사용 가능한 환경을 선택하고, 그 안에 실습용 솔루션을 만듭니다.
```

## 1. 환경과 솔루션 구분하기

| 구분 | 의미 | 이번 실습 |
|---|---|---|
| 환경 | 권한과 데이터 정책 등이 적용되는 작업 공간 | 회사 정책에 따라 교육용으로 사용 가능한 환경 선택 |
| 솔루션 | 관련 구성 요소를 묶어 관리하고 다른 환경으로 이동할 때 사용하는 단위 | 학습자마다 실습용 솔루션 생성 |
| 게시자 | 구성 요소의 게시 주체와 이름 접두사를 정의 | 본인 이름으로 새 게시자 생성 |

솔루션은 개인 저장소나 보안 경계가 아닙니다. 같은 환경의 다른 사용자에게 보이는 범위는 보안 역할에 따라 달라집니다. 또한 솔루션을 만들어도 OneDrive 문서, Excel 내용, 메일이 자동으로 들어가거나 복사되지 않습니다.

## 2. 교육 환경에서 솔루션 메뉴 열기

1. [Copilot Studio](https://copilotstudio.microsoft.com/) 첫 화면에 본인 회사·교육 계정으로 로그인합니다.
2. 환경 선택기에서 사내 운영 정책에 따라 교육용으로 사용 가능한 **Power Platform 환경**을 선택합니다.
3. 왼쪽 하단의 **…**을 클릭한 뒤 **솔루션(Solutions)**을 선택합니다.
4. 솔루션 화면에서 선택한 환경이 맞는지 확인합니다.
5. 목록에서 **새 솔루션(New solution)**을 선택합니다.

## 3. 솔루션과 게시자 설정

아래 `u001`은 예시입니다. 공용 교육 환경에서는 강사가 배정한 본인 식별자로 바꾸어 다른 학습자와 이름이 겹치지 않게 합니다.

| 항목 | 입력 예시 | 설명 |
|---|---|---|
| 표시 이름 | `GHCP 출장 실습 u001` | 목록에서 본인 솔루션을 찾을 이름 |
| 이름 | `GHCPTravelLab_u001` | 영문·숫자·밑줄 사용. 저장 후 변경할 수 없음 |
| 게시자 | 본인 이름으로 만든 새 게시자 | 아래 절차로 생성 후 선택 |
| 버전 | `1.0.0.0` | 초기 실습 버전 |
| 설명 | `출장 준비 도우미 교육용 구성 요소 관리` | 선택 입력 |

**새 게시자 만들기**

1. **게시자** 옆의 **새 게시자(New publisher)**를 선택합니다.
2. 표시 이름에는 본인 이름(예: `홍길동`), 이름에는 영문 이름과 식별자(예: `HongGildong_u001`), 접두사에는 `trvu001`을 입력합니다. 예시는 본인 값으로 바꿉니다.
3. 선택 항목 값 접두사는 자동 제안된 값을 유지하고 **저장**합니다.
4. 솔루션 생성 화면에서 방금 만든 게시자를 선택합니다.

솔루션 정보가 맞는지 확인한 후 **만들기(Create)** 또는 **저장(Save)**을 선택합니다. 생성 후 목록이나 상세 화면에서 **비관리형(Unmanaged)**인지 확인합니다. 이번 과정에서는 관리형 솔루션 가져오기나 내보내기를 수행하지 않습니다.

## 4. 설정 확인과 다음 모듈 준비

솔루션을 닫았다가 다시 열고 다음 항목을 확인합니다.

| 확인 항목 | 기대 결과 |
|---|---|
| 계정·환경 | 본인 계정과 회사 정책에 따라 선택한 교육용 환경이 일치 |
| 표시 이름·고유 이름 | 본인 식별자가 포함된 솔루션 |
| 유형·버전 | 비관리형, `1.0.0.0` |
| 게시자·접두사 | 본인 이름으로 만든 게시자와 접두사 |
| 구성 요소 | 아직 비어 있어도 정상. 다른 학습자의 구성 요소를 추가하지 않음 |

에이전트와 Instructions는 [모듈 3](module03-create-agent-and-instructions.md)에서 만듭니다.

## 완료 체크리스트

- [ ] 본인 식별자가 포함된 비관리형 솔루션을 만들었습니다.
- [ ] 본인 이름으로 새 게시자를 만들고 접두사, 버전을 확인했습니다.
