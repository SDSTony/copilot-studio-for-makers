# 모듈 2. 실습용 솔루션 만들기와 초기 설정

## 학습 목표

- 환경과 솔루션의 차이를 이해합니다.
- 교육 담당자가 지정한 기존 환경에 본인 실습용 비관리형 솔루션을 만듭니다.
- 게시자와 선호하는 솔루션을 설정하고 이후 실습에 사용할 정보를 기록합니다.

## 사전 준비

- 교육 담당자가 지정한 Dataverse 데이터베이스가 있는 Power Platform 환경
- 해당 환경에서 솔루션을 생성하고 게시자를 선택하거나 생성할 수 있는 권한
- 본인의 회사·교육 계정과 강사가 지정한 개인 식별자(예: `u001`)

```{important}
이번 모듈에서는 새 환경을 만들지 않습니다. 교육 담당자가 준비한 환경을 선택하고 그 안에 솔루션만 만듭니다. 메뉴가 없거나 생성 권한이 없으면 담당자에게 확인하며, 임의로 운영 환경이나 다른 환경에 만들지 않습니다.
```

## 1. 환경과 솔루션 구분하기

| 구분 | 의미 | 이번 실습 |
|---|---|---|
| 환경 | 권한과 데이터 정책 등이 적용되는 작업 공간 | 담당자가 지정한 기존 교육 환경 사용 |
| 솔루션 | 관련 구성 요소를 묶어 관리하고 다른 환경으로 이동할 때 사용하는 단위 | 학습자마다 실습용 솔루션 생성 |
| 게시자 | 구성 요소의 게시 주체와 이름 접두사를 정의 | 고객사 지정 게시자를 우선 사용 |
| 선호하는 솔루션 | 지원되는 작성 경로에서 새 구성 요소를 담을 기본 솔루션 | 본인의 교육용 솔루션으로 설정 |

솔루션은 개인 저장소나 보안 경계가 아닙니다. 같은 환경의 다른 사용자에게 보이는 범위는 보안 역할에 따라 달라집니다. 또한 솔루션을 만들어도 OneDrive 문서, Excel 내용, 메일이 자동으로 들어가거나 복사되지 않습니다.

## 2. 교육 환경에서 솔루션 메뉴 열기

1. [Power Apps](https://make.powerapps.com/)에 본인 교육 계정으로 로그인합니다.
2. 환경 선택기에서 강사가 지정한 **교육 환경**을 선택합니다.
3. 환경 이름과 환경 ID를 확인하고 기록합니다. 같은 이름의 환경이 있다면 담당자와 ID까지 대조합니다.
4. 왼쪽 **솔루션(Solutions)**을 선택합니다. 메뉴가 숨겨져 있으면 **더 보기(More)**에서 찾습니다.
5. 목록에서 **새 솔루션(New solution)**을 선택합니다.

이후 Copilot Studio에서도 같은 계정과 환경을 선택합니다. Power Apps에서 솔루션을 만드는 것은 GHCP 대신 Standard 하네스로 에이전트를 만들라는 뜻이 아닙니다.

## 3. 솔루션과 게시자 설정

아래 `u001`은 예시입니다. 공용 교육 환경에서는 강사가 배정한 본인 식별자로 바꾸어 다른 학습자와 이름이 겹치지 않게 합니다.

| 항목 | 입력 예시 | 설명 |
|---|---|---|
| 표시 이름 | `GHCP 출장 실습 u001` | 목록에서 본인 솔루션을 찾을 이름 |
| 이름 | `GHCPTravelLab_u001` | 영문·숫자·밑줄 사용. 저장 후 변경할 수 없음 |
| 게시자 | 고객사 지정 교육용 게시자 | 지정된 게시자가 없다면 아래 절차로 생성 |
| 버전 | `1.0.0.0` | 초기 실습 버전 |
| 설명 | `출장 준비 도우미 교육용 구성 요소 관리` | 선택 입력 |

**새 게시자가 필요한 경우**

1. 교육 담당자에게 새 게시자 생성이 허용되는지 확인합니다. 지정된 게시자가 있으면 새로 만들지 않고 해당 게시자를 선택합니다.
2. **게시자** 옆의 **새 게시자(New publisher)**를 선택합니다.
3. 표시 이름 `GHCP 교육 u001`, 이름 `GHCPTraining_u001`, 접두사 `trvu001`을 입력합니다. 식별자는 본인 값으로 바꿉니다.
4. 선택 항목 값 접두사는 자동 제안된 값을 유지합니다. 고객사 명명 규칙이 있으면 그 규칙을 따릅니다.
5. **저장**한 뒤 솔루션 생성 화면에서 방금 만든 게시자를 선택합니다.

솔루션 정보가 맞는지 확인한 후 **만들기(Create)** 또는 **저장(Save)**을 선택합니다. 생성 후 목록이나 상세 화면에서 **비관리형(Unmanaged)**인지 확인합니다. 이번 과정에서는 관리형 솔루션 가져오기나 내보내기를 수행하지 않습니다.

## 4. 선호하는 솔루션으로 설정

1. 생성 화면에 **선호하는 솔루션으로 설정(Set as your preferred solution)** 항목이 있으면 선택합니다.
2. 생성할 때 설정하지 않았다면 솔루션 목록에서 본인 솔루션을 선택하고 명령 모음의 **선호하는 솔루션으로 설정(Set preferred solution)**을 선택합니다.
3. 목록 또는 환경 선택기의 **선호하는 솔루션** 표시가 본인 솔루션을 가리키는지 확인합니다.
4. 같은 환경에서 기존 선호 솔루션을 변경했다면 원래 값을 기록합니다. 교육 종료 후 필요하면 복원합니다.

```{warning}
선호하는 솔루션 설정만으로 모든 GHCP 에이전트와 Workflow가 이 솔루션에 자동으로 들어간다고 가정하지 않습니다. Copilot Studio의 기존 솔루션 관리 안내는 Standard 하네스 대상으로 명시되어 있습니다. 교육 담당자는 현재 GHCP 환경에서 솔루션 선택과 구성 요소 포함 여부를 별도로 검증해야 합니다. 지원되지 않으면 제한을 기록하고 담당자와 진행 범위를 확인하며, Standard 에이전트를 대신 만들거나 포함되었다고 완료 처리하지 않습니다.
```

## 5. 설정 확인과 다음 모듈 준비

솔루션을 닫았다가 다시 열고 다음 항목을 확인합니다.

| 확인 항목 | 기대 결과 |
|---|---|
| 계정·환경 | 교육 계정과 지정한 환경이 일치 |
| 표시 이름·고유 이름 | 본인 식별자가 포함된 솔루션 |
| 유형·버전 | 비관리형, `1.0.0.0` |
| 게시자·접두사 | 고객사 지정 값 또는 승인받아 만든 값 |
| 선호하는 솔루션 | 본인 교육용 솔루션으로 표시 |
| 구성 요소 | 아직 비어 있어도 정상. 다른 학습자의 구성 요소를 추가하지 않음 |

**확인용 요청 예시**

> 제 실습 환경과 솔루션 설정을 확인해 주세요. 환경은 [교육 환경 이름/ID], 솔루션은 GHCPTravelLab_u001, 게시자는 [게시자 이름], 버전은 1.0.0.0이며 선호하는 솔루션으로 설정했습니다.

이 모듈은 에이전트 생성 전이므로 Preview 프롬프트가 아니라 강사와 함께 화면을 확인하는 단계입니다. 에이전트와 Instructions는 [모듈 3](lab02-create-agent-and-instructions.md)에서 만듭니다.

## 문제 해결

| 증상 | 확인할 사항 |
|---|---|
| 솔루션 메뉴 또는 새 솔루션 버튼이 없음 | 선택한 환경의 Dataverse 구성과 본인 권한을 담당자에게 확인 |
| 이름이 이미 존재함 | 강사가 지정한 본인 식별자를 확인하고 생성 전에 이름 변경 |
| 지정된 게시자를 찾을 수 없음 | 환경이 맞는지 확인하고 담당자에게 게시자 준비 요청 |
| 선호하는 솔루션 설정이 보이지 않음 | 비관리형 사용자 솔루션인지 확인하고 관리자에게 기능·권한 확인 |
| Copilot Studio에서 솔루션 또는 연결된 구성 요소를 찾을 수 없음 | 계정·환경 ID를 대조하고 GHCP의 해당 작성 경로 지원 여부 확인 |

## 완료 체크리스트

- [ ] 새 환경을 만들지 않고 지정된 교육 환경을 선택했습니다.
- [ ] 본인 식별자가 포함된 비관리형 솔루션을 만들었습니다.
- [ ] 게시자와 접두사, 버전을 확인했습니다.
- [ ] 선호하는 솔루션 표시를 확인했습니다.
- [ ] 환경 ID와 솔루션 이름을 기록하고 GHCP 포함 여부의 검증 필요성을 이해했습니다.
