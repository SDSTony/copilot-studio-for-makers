# 모듈 8. Evaluate에서 지식 기반 질문 2개로 평가하기

## 학습 목표

- **평가** 화면에서 테스트 케이스 2개를 직접 입력합니다.
- 여러 테스트 케이스를 하나의 테스트 세트로 묶어 한 번에 평가합니다.
- 케이스별 답변과 평가 결과를 확인합니다.

## 준비

- **출장 준비 도우미**와 기존 Instructions를 사용합니다.
- 본인 OneDrive의 `domestic-travel-policy.docx`, `expense-rules.docx`, `travel-checklist.docx`가 Knowledge에 연결되어 검색 가능한 상태여야 합니다.
- Evaluate 사용 권한과 Copilot Credits를 확인합니다. 평가 실행도 사용량에 포함됩니다.

## 1. 평가에서 테스트 케이스 만들기

1. 에이전트의 **평가** 탭에서 **새 평가**를 선택합니다.
2. 화면 아래의 **또는 직접 질문을 작성해 보세요.**를 선택합니다.
3. **대화 추가 > 작성하기**에서 아래 첫 번째 질문을 입력합니다.
4. 두 번째 케이스도 **별도 대화**로 추가합니다. 한 대화에 두 질문을 이어 넣지 않습니다.

### 테스트 케이스 1. 국내 숙박비 한도

**User question**

```text
교육용 국내 출장 규정에서 숙박비는 세금을 포함해 1인 1박당 얼마까지인가요?
한도를 초과하면 어떻게 안내해야 하나요? 근거 문서도 알려 주세요.
```

### 테스트 케이스 2. 교통비 기준

**User question**

```text
교육용 경비 기준에 교통비의 고정 금액 한도가 정해져 있나요?
어떤 교통수단과 금액 범위로 계획해야 하는지 근거 문서와 함께 알려 주세요.
```

## 2. 두 테스트 케이스를 한 번에 평가하기

1. **테스트 케이스 검토**에서 독립된 케이스가 **2개**인지, 질문이 올바르게 들어갔는지 확인합니다.
2. 오른쪽 **테스트 세트 구성**의 **평가 이름 입력**에 **출장 규정 지식 확인 v1**을 입력합니다.
3. **테스트 방법**은 **일반 품질**을 선택합니다. 이 방법은 별도의 기대응답과 비교하지 않고 응답의 관련성·완전성 등 품질을 평가합니다.
4. **사용자 프로필 > 관리**에서 Knowledge에 접근할 수 있는 **본인 계정**을 확인합니다.
5. **저장**한 뒤 **평가**를 클릭하고 완료를 기다립니다. 두 케이스가 하나의 테스트 세트로 함께 실행됩니다.

## 3. 결과 확인

**평가** 목록에서 **마지막 실행 상태**가 **완료됨**인지 확인하고 해당 평가를 엽니다. 테스트 세트의 전체 결과와 각 케이스의 실제 답변·평가 결과를 확인합니다.

| 케이스 | 사람이 확인할 내용 |
|---|---|
| 1 | 세금 포함·1인 1박·130,000원이 정확하고, 초과 시 별도 검토와 올바른 문서 근거를 안내하는가? |
| 2 | 고정 금액 한도를 만들지 않고, 대중교통/일반석·전체 왕복 예상 금액·올바른 문서 근거를 안내하는가? |

Preview에서 질문을 하나씩 보내는 대신, **여러 테스트 케이스를 한 번에 실행하고 결과를 함께 확인**할 수 있습니다. 질문이 늘어나도 같은 테스트 세트에서 일괄 평가할 수 있다는 점을 확인합니다.

## 완료 체크리스트

- [ ] 평가에서 질문만 입력하여 독립 케이스 2개를 만들었습니다.
- [ ] 테스트 방법을 일반 품질로 설정하고 본인 사용자 프로필을 확인했습니다.
- [ ] 두 케이스를 하나의 테스트 세트로 저장하고 한 번에 평가했습니다.
- [ ] 평가 완료 상태와 케이스별 실제 답변·평가 결과를 확인했습니다.
- [ ] 여러 테스트 케이스를 일괄 평가하는 방법을 이해했습니다.
