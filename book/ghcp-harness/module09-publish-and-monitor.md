# 모듈 9. 본인 전용으로 게시하고 실제 사용을 모니터에서 확인

## 학습 목표

- **출장 준비 도우미**를 게시합니다.
- 게시한 채널에서 에이전트와 대화합니다.
- 하루 정도 뒤 **모니터**에서 집계된 사용 현황과 세션을 확인합니다.

## 준비

- 앞선 모듈에서 만든 **출장 준비 도우미**를 사용합니다.
- 본인 회사 계정으로 사용할 수 있는 게시 채널을 확인합니다.

## 1. 에이전트 게시하기

1. **출장 준비 도우미**를 열고 오른쪽 위의 **게시**를 클릭합니다.
2. 게시 화면에서 **Teams + Microsoft 365** 채널을 활성화하고 게시를 완료합니다.
3. 게시한 채널에서 본인 계정으로 에이전트를 엽니다. 이번 실습에서는 본인만 사용하고 다른 사용자에게 공유하지 않습니다.

## 2. 게시한 채널에서 대화하기

**미리 보기**가 아니라 게시한 채널에서 새 대화를 시작하고 아래 질문을 입력합니다.

```text
교육용 국내 출장 규정에서 숙박비는 세금을 포함해 1인 1박당 얼마까지인가요?
근거 문서도 알려 주세요.
```

에이전트가 응답하는지 확인하고, 사용한 채널과 대화한 시각을 기억해 둡니다. 이후 **모니터**에서 해당 세션을 찾을 때 사용합니다.

## 3. 하루 정도 뒤 모니터 확인하기

사용 현황은 대화 직후 바로 집계되지 않을 수 있습니다. **하루 정도 뒤 다시 접속해 확인합니다.** 이는 실습에서 여유를 두고 확인하는 시점이며, 항상 하루가 걸린다는 의미는 아닙니다.

1. 에이전트 화면 위쪽의 **모니터** 탭을 선택합니다.
2. 오른쪽 위의 **지난 7일** 메뉴에서 조회 기간을 설정할 수 있습니다.
3. **개요**에서 다음 지표를 확인합니다.

   | 화면 항목 | 확인할 내용 |
   |---|---|
   | 총 세션 수 | 선택한 기간에 집계된 대화 세션 수 |
   | 총 사용자 수 | 에이전트를 사용한 사용자 수 |
   | 평균 소요 시간 | 세션의 평균 소요 시간 |
   | 성공 비율 | 집계된 세션의 성공 비율 |
   | Total credits used | 집계된 크레딧 사용량 |

## 완료 체크리스트

- [ ] 에이전트를 게시하고 본인 계정으로 게시 채널에서 열었습니다.
- [ ] 게시한 채널에서 규정 질문을 입력하고 응답을 확인했습니다.
- [ ] 하루 정도 뒤 모니터에 접속했습니다.
- [ ] 개요의 사용 지표에서 집계된 사용 현황을 확인했습니다.
